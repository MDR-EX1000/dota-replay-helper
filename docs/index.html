一、评分口径

综合分 = 0.6 × Elo + 0.4 × 表现分

Elo 本身已经包含胜负信息，所以不再单独加胜率分，避免重复计算；胜率只在数据表中展示。

Elo：初始 1000，K=32。每场按队伍平均分计算期望胜率，再给 5 人同步加减。

表现分：绝对数值 + 位置基准（不做百分位排名），权重统一：

指标权重基准（核心 / 酱油）
KDA40%3.7 / 2.4
GPM15%540 / 335
XPM15%720 / 490
伤害/经济30%1.59 / 1.40

原始表现 = 1000 + 500 × Σ[权重 × (实际值/基准值 − 1)]
再按场次收缩：1000 + (原始表现−1000) × n/(n+5)。

二、Roll 规则

规则要求说明
R1 名单结构建议 6 核 + 4 辅非硬门槛；不满足记 WARN，仍可正常 roll
R2 每队结构两队核心数差 ≤ 1按实际名单尽量均衡，不强制固定 3 核 2 辅
R3 均分差两队综合均分差 ≤ 10强度接近
R4 预测胜率45% – 55%按 Elo 公式计算
R5 不堆叠综合分前 2 名不同队避免双强同队

若没有方案同时满足 R1–R5，按固定顺序放宽并在结果中注明：
1. 放宽 R5 → 2. 把 R3 放宽到 15 → 3. 把 R4 放宽到 40%–60%。

三、为什么这样 roll 没问题

  1. 结构约束：只保留两队核心数差 ≤1 的分法，按实际名单尽量均衡。
  2. 强度硬约束：均分差和预测胜率必须在线内，不达标不进池。
  3. 随机只在合格池内：池内方案胜率几乎相同，抽中哪套对胜负影响可忽略。
  4. 规则审计：每套结果都会列出 R2–R5 的实际值和 PASS/FAIL，现场可核对。
  5. 可复现：网页每次 roll 的方案、池子、时间都可见；脚本版还会记录随机种子并落盘。
